# Введение в физику нейтрино

В папке хранится архив HTML-экспортов вводного курса из Keynote. Каждая лекция
лежит в отдельной подпапке с собственным `index.html`.

Новые публичные материалы по физике нейтрино лучше добавлять через актуальные
страницы `ru/education.qmd`, `en/education.qmd` или отдельный проект
`neutrinophysics`. Плейсхолдерные `.qmd`-страницы в этой папке не входят в
основной render сайта.
