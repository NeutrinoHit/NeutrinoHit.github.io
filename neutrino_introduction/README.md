# Введение в физику нейтрино

В папке хранятся вспомогательные материалы вводного курса.

Новые публичные материалы по физике нейтрино добавляются через актуальные
страницы `ru/education.qmd`, `en/education.qmd` или отдельный проект
`neutrinophysics`. Плейсхолдерные `.qmd`-страницы в этой папке не входят в
основной render сайта.
