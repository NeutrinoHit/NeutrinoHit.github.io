# Обложки книг NeutrinoHit

Это канонический воспроизводимый источник SVG-обложек авторской серии Дмитрия
В. Наумова:

- «Статистические методы в физике»;
- «Введение в физику нейтрино»;
- «Введение в физику элементарных частиц»;
- «Гравитация».

У серии общий модуль: бирюзовая вертикаль, крупная антиква для названия и
отдельный предметный цвет. Фон может меняться между дизайн-итерациями. На лицевой
стороне нет нумерации, логотипа и слова NeutrinoHit: фирменный знак остаётся только на
обороте. Верхняя зона лица свободна для будущих знаков Teach-in, издателя и ОИЯИ.
Научный образ каждой книги строится кодом и остаётся редактируемым в SVG.

## Готовые SVG

Файлы находятся в `svg/v1/`:

- `*_front.svg` — лицевая сторона;
- `*_back.svg` — задняя сторона;
- `*_spread_mockup.svg` — макет полного разворота с временным корешком;
- `artwork/*.svg` — самостоятельные научные иллюстрации;
- `series_overview.svg` — обзор всей серии.

В `svg/v2/` находятся актуальные рабочие итерации статистической и нейтринной книг. Для
статистической книги это тёплое бумажное поле,
абсолютные ожидаемые спектры с осцилляциями и без них, узкая полоса остатков и
определение профильного отношения правдоподобий. Файл `statistical_methods_overview.svg`
показывает лицо и оборот рядом. Нейтринная обложка использует ту же сетку на глубоком
звёздном фоне; её научный образ — аккрецирующая чёрная дыра, релятивистский джет
и линзированный свет диска. Источник уменьшен и повёрнут примерно на 40,6° от вертикали:
ось джета и ось черенковского конуса лежат на одной композиционной диагонали.
Видимая светящаяся часть джета сужается над внутренней областью диска; тёмная
тень не содержит ни светящегося потока, ни магнитных линий.
Справа расположен условный кластер Байкал-GVD:
восемь гирлянд со сферическими оптическими модулями, черенковский свет и подсветка
сработавших модулей. Отдельных нейтринных траекторий и подписей к источнику и телескопу нет.
Скетч телескопа строится в `source/baikal_gvd_sketch.py`, чёрной дыры —
в `source/black_hole_sketch.py`. Палитра, масштабы и размещение заданы
в `config/neutrino_v2.json`; угол источника вычисляется из оси светового конуса.

Звёздное поле оформлено как **Neutrino Sky Atlas**. Английские названия набраны
курсивом Cochin: Unitarity Constellation, Oscillation Constellation, Hierarchy
Constellation, Big Bang Relics, Anomaly Clouds, Majorana Cluster, CP Bridge и
BSM Portal. Внизу — небольшой картуш Neutrino Sky / ATLAS. Вымышленные небесные
объекты строятся в `source/neutrino_constellations.py` и `source/neutrino_atlas_motifs.py`;
параметры и размещение — в секции `constellations` файла `config/neutrino_v2.json`.

Треугольник вычисляется из PMNS-матрицы. Осцилляционный мотив — одна волна из
17 звёзд переменной яркости, связанной с вероятностью сохранения мюонного флейвора.
Иерархия изображена как весы с двумя символическими массовыми тройками. Остальные
объекты — художественные метафоры, не карта реального неба и не заявления об открытиях.
Самый приглушённый мотив, BSM Portal, находится в нижней правой части иллюстрации.

В `svg/v2/variants/` сохраняются:

- `neutrino_physics_front_labeled.svg` — английские названия курсивом Cochin;
- `neutrino_physics_front_unlabeled.svg` — те же фигуры без видимых названий;
- `neutrino_physics_constellations_comparison.svg` — два варианта рядом.

Названия — отдельный SVG-слой `constellation-labels` с меткой «Названия созвездий»
для Inkscape. Вложенные обложки добавляют префикс к ID, но сохраняют метку слоя.
Варианты различаются только `display:inline` / `display:none` у этого слоя.
Флаг `constellations.labels_visible` выбирает вариант для канонической лицевой стороны,
обзорных листов и разворота; по выбору автора названия включены. Вариант без них
сохранён как вспомогательный экспорт. Новых подписей к ЧД и Байкалу нет.

Оборот нейтринной книги использует одобренную цельную аннотацию «От квантового
состояния к экспериментальному открытию», отдельный авторский блок с регалиями
и двумя международными наградами в составе Daya Bay. Источник текста —
`config/neutrino_back.json` (бывший `neutrino_back_proposal.json`), вёрстки —
`source/neutrino_editorial_back.py`. Светлый логотип сохраняет исходную геометрию.
Ранние ссылки на `svg/proposals/` поддерживаются дополнительным экспортом того же
актуального дизайна; это больше не альтернативная версия текста.

SVG не содержат `<image>`, data URI или внешних изображений. Растровые превью
не являются исходниками и в репозиторий не включаются.

## Быстрая регенерация

### Обложки в HTML и PDF книг

Каталог `published/` содержит публикуемые векторные SVG и одностраничные PDF
актуальных лицевых и задних обложек. Эти файлы хранятся в Git: обычная сборка
книг использует готовые локальные копии и не требует соседнего репозитория,
Inkscape или установленных шрифтов обложки. В печатных и веб-экспортах текст
переведён в контуры; редактируемый текст остаётся в `svg/v2/`.

После изменения дизайна выполнить из корня `neutrinohit-map`:

```bash
make export-book-covers
make sync-book-covers
make check-book-cover-sync
```

Для экспорта нужны Inkscape, librsvg (`rsvg-convert`), Poppler (`pdfimages`) и рабочие шрифты,
перечисленные ниже. `INKSCAPE` позволяет указать путь к исполняемому файлу.
Бинарная маска тени ЧД в экспортной копии заменяется геометрически эквивалентным
векторным отсечением: джет не попадает внутрь тени, растровой маски в PDF нет.

Синхронизация затрагивает только `assets/covers/` русских книг в `stat-course`
и `neutrinophysics`; главы и остальные стили не изменяются. Общие CSS и TeX
в `integration/` обеспечивают обложку и раскрывающийся оборот в HTML, а также
первую и последнюю страницы PDF без полей и колонтитулов. Именованная PDF-цель
`neutrinohit-back-cover` отделяет оборот от последней главы при её извлечении.

Из корня `neutrinohit-map`:

```bash
make book-covers
make check-book-covers
```

`source/generate_series.py` использует только стандартную библиотеку Python.
`source/generate_statistical_v2.py` дополнительно использует NumPy для чтения канонического NPZ и Matplotlib
mathtext для превращения LaTeX-формул в векторные контуры. Тексты, цвета, ручные переносы и временная ширина
корешка хранятся в `config/series.json`, `config/statistical_v2.json`, `config/neutrino_v2.json`
и `config/neutrino_back.json`. Оборот использует метрики Matplotlib для переноса текста.
`make check-book-covers` проверяет 32 SVG, в том числе совместимость старого редакционного
экспорта, сохранность аннотации и регалий, общую ось источника и сигнала, восемь гирлянд,
288 оптических модулей и исключение светящегося потока из тени. Дополнительно проверяются
унитарность PMNS-матрицы, геометрия треугольника, нормировка вероятностей, единственная
звёздная волна и отображение вероятности в радиусах звёзд, два порядка масс в чашах весов,
все восемь мотивов, английские названия, картуш и идентичность вариантов вне слоя названий.

## Полный пересчёт статистической иллюстрации

Тяжёлый JUNO-like расчёт и построение профильного правдоподобия сохранены из
первого прототипа. Для них нужны зависимости из `requirements-full.txt`:

```bash
python -m pip install -r assets/books/covers/requirements-full.txt
make book-covers-full
```

Полный расчёт обновляет канонический NPZ в `data/`, пересобирает
`source/artwork/statistical_methods_juno.svg`, затем обновляет всю серию.
Физические допущения перечислены в `docs/AUDIT.md`.

## Производственный статус

- Формат 210 × 297 мм пока рабочий, а не утверждённый типографский формат.
- Развороты используют временный корешок 18 мм и не содержат вылетов.
- ISBN, штрихкод и издательские знаки намеренно не добавлены.
- Текст обложки остаётся live text. После утверждения формата и формулировок
  его следует перевести в кривые отдельным печатным экспортом; исходный SVG с
  редактируемым текстом нужно сохранить.
- В репозитории не распространяются файлы шрифтов. Рабочие семейства:
  Noto Serif Display / PT Serif, Inter / Arial и Cochin для английских подписей атласа.
