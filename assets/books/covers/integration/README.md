# Обложки книги

`front.svg`, `back.svg`, `front.pdf` и `back.pdf` — публикуемые статические
векторные ресурсы, хранящиеся в Git вместе с книгой. Текст переведён в контуры,
поэтому сборка и просмотр не требуют шрифтов обложки. SVG используются в HTML,
PDF — на первой и последней страницах полной PDF-книги.

Канонический дизайн, редактируемые SVG и генераторы находятся в соседнем
проекте `neutrinohit-map/assets/books/covers/`. Обновление из его корня:

```bash
make export-book-covers
make sync-book-covers
make check-book-cover-sync
```

Не редактировать эти копии вручную. `covers.css`, `covers.tex` и
`back-cover.tex` также синхронизируются из канонического каталога `integration/`.
Обычная сборка книги работает независимо от соседних репозиториев.

В полной PDF-книге обложка занимает первую, правую страницу и учитывается
в счётчике предварительных страниц. После неё счётчик не сбрасывается:
переход к арабской нумерации выполняет штатная команда `\mainmatter`.
Так чётные страницы остаются слева, нечётные — справа, а широкие поля
и цветные номера — снаружи разворота. PDF задаёт режим `TwoPageRight`;
просмотрщик может переопределять его своими настройками.

После изменения подключения обложек проверить первые страницы и разворот
в середине обеих книг. Физическая страница PDF с арабским номером должна
иметь ту же чётность, что и напечатанный номер. Геометрию полей и условие
чётности в боковом навигаторе для исправления сдвига менять не следует.
