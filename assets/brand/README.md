# Знак NeutrinoHit и фирменные материалы

Все фирменные файлы NeutrinoHit собраны здесь или перечислены ниже. Если нужен
логотип, шрифт или цвет, сначала загляните сюда.

## Логотип

Логотип — макроскопическая фейнмановская диаграмма: нейтрино проходит сквозь
Землю между двумя вершинами слабого взаимодействия, всё это внутри кольца.

| файл | что это | где брать |
|---|---|---|
| `neutrinohit-logo.svg`, `.pdf` | вектор: кольцо, белый диск, рисунок | книги, обложки, страницы для автографа, печать, слайды на любом фоне |
| `neutrinohit-logo-line.svg`, `.pdf` | тот же рисунок без белого диска | светлая бумага, где диск не нужен |
| `neutrinohit-logo-1024.png` | растр 1024 px из вектора | веб и программы, которым нужен PNG |

Вектор строится из растрового мастера скриптом `scripts/build_brand_logo.py`.
Кольцо и белый диск в нём — точные окружности, рисунок обведён по мастеру при
удвоенном разрешении. Чтобы пересобрать:

```bash
python3 scripts/build_brand_logo.py
```

Нужны numpy, Pillow, OpenCV и `rsvg-convert`. Цвета чистые: чёрный `#000`,
белый `#fff`. Снаружи кольца фон прозрачный.

### Не путать

- `assets/books/covers/source/brand/neutrinohit_logo.svg` — упрощённый вариант
  для обложек. Там другой поворот Земли и грубая береговая линия, это не сам
  логотип.
- `TheBook/images/FrontPage/dvn_logo.pdf` — старый зелёный глобус, растр внутри
  PDF. Использовать не нужно.

## Шрифты и цвета

- **Книги:** Libertinus Serif, Sans и Mono (`assets/books/neutrinohit-book.tex`).
- **Слайды:** тёмная тема. Фон `#000000`, текст `#f2f2f2`, ссылки `#7cc7ff`
  (`assets/reveal/neutrinohit-reveal.scss`).
- **Сайт:** токены в `assets/site/neutrinohit-tokens.css`.

Новый фирменный файл кладите в эту папку и добавляйте в таблицу выше.
